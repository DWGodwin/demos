**The catch is the project's no-dependencies rule.** `GUIDE.md` says Google Fonts is the only external load and every page must work without it. That gives two options:

1. **Load KaTeX or MathJax from a CDN.** This is the easiest route but breaks that rule. Offline, the formulas would show up as raw LaTeX.
2. **Turn the LaTeX into MathML when the site is built (my recommendation).** All modern browsers now display MathML natively, so the built pages need no script, stylesheet or font. The pages stay single files and keep working offline. The cost is one new build dependency. That would be either Temml run through Node (Node is already used for the tests) or the Python `latex2mathml` package installed through pixi. `build.py` would replace something like `<tex>U_i = p_{ii}/p_{i+}</tex>` with the MathML, and `check.js` would check that no raw `<tex>` tags reach the built pages.

The equations would appear in the browser's serif math font, which won't match the pixel look. I think that works in our favour, because it makes them read as quotes from the paper.

**Optional extra:** the numbers inside an equation could update with the sample. For example, explainer 02 could show `p̂₄₄ = 0.05 × 11/25` while the reader re-tastes. This works with prebuilt MathML too, because the script only has to swap the numbers.
